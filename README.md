# chain (redirect)

The daily word puzzle Chain was renamed **Dwindle**. This repository only exists so the old
address, https://stevesul.github.io/chain/, forwards to https://stevesul.github.io/dwindle/.

`index.html` handles the old home page and `404.html` catches any other old path. Both keep
the query string and hash, so test links like `?date=2026-11-10` still work.

The game's code lives at https://github.com/stevesul/dwindle.
